# Sunloop

Cliente de música de código abierto para **Android** y **Windows** que reproduce el catálogo de YouTube Music.

> **Estado:** en desarrollo. Todavía no hay versión pública.

"Shura" es el nombre interno del proyecto (código y paquete `io.github.javiernarvaezz.shura`); el nombre público es **Sunloop**.

## Qué es y qué no es
- Es un cliente independiente. No aloja ni distribuye música.
- Usa una API no oficial de YouTube Music, así que puede dejar de funcionar si ellos cambian algo y va contra sus términos de servicio.
- **Sunloop no está afiliado, patrocinado ni respaldado por YouTube ni por Google.** YouTube y YouTube Music son marcas de Google LLC.
